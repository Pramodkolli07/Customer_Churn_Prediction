# Customer Churn Prediction
## Overview:
Customer Churn Prediction is a Machine Learning project which helps us to predict whether a customer of network based company (Wi-Fi) will stay or leave using that network with help of the customer's account and serviece information
## Technologies Used

- Python

- Pandas and NumPy

- Matplotlib and Seaborn

- Scikit-learn

- Google Colab
## Results

- Model: Logistic Regression with class balancing

- Accuracy: approx 73%

- Recall for customers who churned: approximately 79%

## How to Run

- Open Customer_Churn_Analysis.ipynb.

- Upload the Telco Customer Churn CSV dataset to your Google Colab environment or connect Google Drive.

- Run the notebook cells in order.
